## About

I wanted a portfolio I had actually written myself rather than one assembled from a theme, so everything here is hand-written HTML and CSS. The layout, the colour system (purple is a sick color!) and the responsive behaviour are all my own.

The site is deployed straight from this repository with GitHub Pages.

## Built with

- HTML5
- CSS3 custom properties (design tokens)
- GitHub Pages for hosting

## Design system

Colours, spacing and typography are defined once as CSS custom properties and reused throughout, so the whole site can be re-themed from a single block:

```css
:root {
  --color-bg: ...;
  --color-text: ...;
  --space-md: ...;
}
```

The site uses a dark theme by default and is fully responsive. The layout adapts down to mobile widths.
